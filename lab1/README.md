# Лабораторная 1. Вариант 8

Блочно-итерационный шифр по пособию Н. Н. Шенца. Блок и ключ — 32 бита. Параметры варианта лежат в `instructions_8.in`.

Раунды `tfssl`: обмен полублоков, Фейстель, две SP-сети, Лай–Месси. Дополнение — маркер-бит `1` и нули до кратности блока. Сложение с ключом — XOR, P-блок — `15·i + 26 (mod m)`.

Программа на Go читает инструкцию, проверяет `example1`–`example3` и шифрует десять файлов. Блочный шифр лежит в пакете `cipher`, его же берёт лабораторная 2.

```
go run .
```

Каталоги:

- `in/` — открытые тексты `test1.in` … `test10.in`
- `key/` — ключи `key1.in` … `key10.in`
- `out/` — шифртексты `test1.out` … `test10.out`

Примеры и `instructions_8.in` лежат рядом с кодом.
